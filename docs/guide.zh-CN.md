# Nautilus Log 使用指南

[返回 README](../README.zh-CN.md) · [English](./guide.md)

## 计划格式

把固定事件与弹性任务写成 Nautilus Log 组件的直接子级。Roam block 顺序就是任务优先级。

```text
05:00-06:00 Morning routine
{{[[TODO]]}} 撰写项目简报 45m
{{[[TODO]]}} 复习笔记 30m
11:45-12:30 Lunch
```

- 时间范围会被识别为固定事件。
- 没有时间范围的直接子级会被识别为弹性任务；TODO 可省略，DONE 则不进入今天的执行。
- 预计时长支持 `30m`、`30min`、`1h` 和 `1h30m`。
- 没有时长的任务使用 **Default Todo Duration**。
- **Urgent Trigger Word** 只改变任务颜色，不改变排程顺序。
- 裸 block 引用继承来源的 TODO/DONE；若要在今天重做已完成的来源内容，请在引用外层加 TODO。
- 单一引用后写入的时长覆盖来源时长。可见且有效的来源 `dHH:MM` 会按当前计划的时钟解读为估计终点，项目页和较早 Daily Note 也一样；它不是已证实的完成日期，也不是 Actual。明确的本地完成信息及本地 CLOCK 优先。来源 CLOCK 不继承，也不把来源时间写进本地包装块。
- 旧的 `dNN%` 文本不再具有排程含义。Nautilus Log 会把它保留为普通 block 文字，并始终按
  完整预计时长排程。

## 可选完成时间戳

**完成时间戳**是独立设置，默认关闭，不需要开启执行层。经确认的用户完成操作可以在末尾追加一个本地 `dHH:MM`。图表可结合这个时间和任务预计时长推算区间；时间戳本身不计量 Actual，也不会启动 CLOCK/POMO。

支持主大纲、右侧边栏和 Nautilus Desk 的原生复选框、Cmd/Ctrl+Enter，以及 Nautilus 自身的完成命令。引用中的复选框跟随 Roam 实际修改的源块；明确写在外层的任务标记属于外层块。快捷键可以先由 Roam 提交当前编辑文字，再追加时间；尚未提交或仍在输入法组合中的文字不会被覆盖。目标不明确、选择超过 20 个块、无法读取，或图谱、用户、provider 发生变化时，会跳过时间写入。

首次点击后，Roam 的图谱提交与原生编辑器重绘可能先后完成。Nautilus 在有限窗口内等待两者一致，再写时间戳；锁忙或变化未确认超时时会提示，不会对后来被动变化补写。时间戳写入一旦发出，就由自己的确认与归属保存流程收尾，不再被先前的观察期限取消。

重新打开任务时，只删除仍能确认由 Nautilus 写入的那个末尾时间。先撤销并回读归属记录，确认后才删除时间；撤销未确认时保留时间，后续删字未确认时也不会恢复旧归属记录。成功重新打开后，再次完成会记录新时间。手写、旧插件、日历、重复、格式错误或代码字面量里的时间会保留。归属信息以 SHA-256 元数据保存在扩展设置中，最多保留最近 64 条，大小上限 32 KiB，不保存任务正文或完成历史。正文改动、归属记录丢失或损坏、超出保留数量，以及另一客户端设置未同步，都可能使旧时间无法安全删除。归属信息保存失败时，会保留已经写入的时间并提示；Roam 未确认的写入不会自动重试，请先检查块内容。

启动、渲染、导航、导入、同步及已有 DONE 不会触发补写。Undo/Redo 仍交给 Roam，原生完成和后补时间可能需要分别撤销。浏览器验收使用隔离图谱和模拟原生结构，没有据此宣称真实 Roam Desktop、系统输入法或原生单步撤销已通过实机验收。

检测到 Todo Trigger 正在运行时，Nautilus 会暂停时间写入，因为对方可能独立追加。Nautilus 不读取或修改它的配置。启用本开关前，请在每个客户端停用 Todo Trigger；仅关闭它的 Append Text 选项不会解除这个冲突检测。

## 排程规则

1. 固定事件先占用自己声明的时间范围。
2. 按照 Roam block 顺序读取尚未完成的直接子级任务。
3. 从当前时刻开始，把完整任务放进下一个足够大的连续空档。
4. 时间经过后，未完成任务向前推进，但不改变优先顺序。
5. 到设定结束时间仍放不下的任务进入 **今日放不下**。

排程规则完全确定，不会自动生成时长。每项任务保持完整：当前空档放不下时，任务会跳到
下一个合适空档，而不是被任意切开。

弹性任务按自身顺序使用全天空档，不受固定事件在大纲中的位置限制。“任务遵循事件位置”功能已经移除，
旧设置即使仍保存为开启，也不会再影响排程。

固定事件标为 DONE 后，写明的范围仍保留到结束；要提前释放，应修改或删除时间范围。
大纲编辑或 Desk 移动可以改变任务之间的优先顺序，但仅把任务移过一个固定事件行，不会再附加最早开始时间。

当前时间仍在固定事件内时，后续待办可以一直保持在该事件结束后开始，
不是卡住了；到 END 放不下的任务则明确标为未排入。分钟计时器与页面恢复可见、聚焦、返回时的校准共用
墙钟快照，同时记录日期，避免隔日同一分钟恢复时沿用旧状态。

## 顶部指标

| 指标 | 含义 |
| --- | --- |
| Planned | 剩余弹性任务需求；`未分配` 是未分配预算 ÷ 全天弹性容量，不是剩余钟表时间或精力 |
| Remaining | 安排完 Planned 后的余量 |
| Overload | 超出当前可用时间的需求 |
| 空档不足 | 总时间存在，但没有连续空档能容纳某项完整任务 |
| Available | 当前剩余弹性时间 / 完整时段弹性时间总量 |
| Events | 当前剩余事件时间 / 完整时段事件时间总量 |

重叠事件按时间并集计算，同一分钟不会重复统计。小火焰表示当前正在消耗 Available
还是 Event 时间。

## 视觉语言

- Roam 原生蓝：弹性任务；当前时段的任务使用更强填充和描边
- 低饱和金黄：固定事件
- 灰色配实线边界：本地 CLOCK 实际记录，或写明固定时段的完成项
- 灰色加虚线轮廓：使用估计时长的完成任务；Tips 区分完成戳锚定与估时排布
- 浅底淡斜线：已经过去、未被任务或事件区间覆盖的空档，不是未来余量
- 原色上的细斜线：该区间已经过去的部分，不代表事件实际执行或记录过真实用时
- 红色指针：现在，也是待办开始排入未来空档的边界
- 红色任务：显式紧急标记覆盖普通色彩

任务蓝色 `#137cbd` 和 Free 绿色 `#277a59` 保持原有含义；工具栏使用独立的中性灰。
任务文字用深一档的蓝色 `#106ba3`，事件用较沉稳的金黄 `#ad8b24`，紧急色用较柔和的红色 `#c24b4b`。
时间片、连线、「未完成」提示和深色模式文字沿用对应色系，不改变原有含义。

斜线只叠在当前时刻之前的部分，原有底色、渐变和透明度不变，未来部分保持纯色。黄色斜线表示事件时段已过去，不证明事件已经执行；灰色斜线也不会把估时变成实际记录。估时的虚线轮廓仍在纹理上方，文字、指针及交互不受遮挡。完成项始终显示并占用原有区间，不会变成空档。

**连续薄壳**让每条定时记录成为一个完整曲面，半径变化的肩部与峰顶采用圆顺过渡；整点只作为边缘刻度，不再把任务视觉上切成多个小片。
标题下不再显示时长／Actual／Estimate 备注，仅当前时段的任务显示 **Current task／当前任务**、事件显示 **Current event／当前事件**，使用与时间指针一致并适配深色主题的红色；任务／事件标题保留分类颜色。「当前」指当前图表时段，不证明正在执行，也不代表已开启 CLOCK。完整时长与完成状态仍在悬停／聚焦的 Tips 中。CLOCK 可以正在记录另一项任务，不会因此转移当前时段标签或改写你的顺序。
中心时钟沿用界面字体与等宽数字，采用常规字重和随主题变化的次级文字色；字号上限 16px，窄视图仍自适应。日期、时钟位置和指针不变。
曲线保留半径逐渐收束的模型和真实时间边界，但不宣称与旧的阶梯形图形像素面积相等。

悬停或键盘聚焦时，同步强调时间片、连线与彩色标题，SVG 本身不移动。界面默认英文，明确设置的中文偏好仍然有效；
任务标题始终保留源语言，不翻译、不改写。顶部图标样式保持不变。

Actual 是 CLOCK 时长之和；图中连续区间只是以完成时刻为锚的投影，不是会话时间线。例如 CLOCK 09:00–09:40 加 `d15:00` 画为 14:20–15:00；09:00–09:15 加 10:00–10:15 画为 09:45–10:15。LOGBOOK 会话保持原样，Tips 明确区分**合计**与**绘图区间**。

采用估时的完成任务在标题旁保留小型 `≈`，包括用完成戳锚定的估时。标记参与宽度测量与换行，不挤掉此前可见的标题字，也不为每条记录增加一行副标题；无障碍文本和 Tips 会说明时长采用估计值。

未实际计时的完成任务，按写明的估时绘制；没写则用默认任务时长，默认是 **15 分钟**。
它们直接获得海螺切片和连接标签，不以 CLOCK 或完成戳为门槛。没有本地时间锚点时，
从 START 开始，按大纲顺序将完整估时排入固定事件和已有锚点完成片之间的空档。
提示明确写「估时排布」，不冒充记录过的完成时刻。本地完成戳只能锚定估计区间的终点，不能把估时变成 Actual；这类完成任务也保留虚线轮廓，悬停或展开时不会被实线覆盖。

估时位置不随红针移动，也不改变待办排程。估时可能排到现在之后，与待办预测重叠；
灰色虚线轮廓区分估时，待办仍保留蓝色填充。整个配置窗口确实放不下时，保留任务标题和时长，
用容量溢出端点表示；不拆任务、不让后面的短任务越过它，也不延长 END。
未排入的待办进入图下默认折叠的「未排入」队列，不放在海螺里没有时间含义的位置。已知区间完全在显示时段外时，不加特殊图标，仍使用普通标题和连线：开始前连接 START，结束后连接 END。连到边界不代表占用了该时段，也不改写完成时间。例如 20:43–21:28 的完成记录在 END 为 20:00 时连接 20 点边界；原始区间和「显示时段外」说明仍保留在悬停／聚焦的 Tips 中。

悬停或聚焦标题，会强化当前标题—连线—切片的整条关系。
完成标题保持中性灰蓝，不再画删除线；其他正文仍可读。点击任务仍只定位原 block，不是在图上勾选完成。

过去空档描述的是图上的时间分配，不证明那段时间闲置或“被浪费”。

## 图表控制

三个主控件依次为 **Desk → 帮助 → 眼睛**。已连接日历时，Calendar 作为第四个按钮排在它们后面。帮助和眼睛使用原版 Blueprint 实心图形，尺寸为 18px；Desk 使用状态清楚的实心轨道开关。悬停与切换反馈约 100ms，不做图标变形或按钮缩放；减少动态效果模式下近似即时。点击范围和键盘焦点保持不变。

- **Desk 滑动开关：** 显示／隐藏图下的未完成任务卡片。平时只显示滑块，悬停或键盘聚焦才显示 Desk 提示；开启时滑块右移、轨道变蓝，关闭时为中性灰实心轨道。支持点击、Space 和 Enter。关闭面板、折叠恢复或读取已保存偏好时，状态同步更新。
- **帮助（?）：** 紧接 Desk 开关。点击打开原生风格速查卡，显示当前图表的有效时段和默认任务时长，解释可安排、事件、已计划和未分配比例，并说明排程、Desk 与完成样式。卡片也提供设置位置和完整指南。它只读，不另造设置编辑器；再次点击、点击外部或在帮助内按 Esc 可收起。
- **Eye off／Eye：** 展开时显示 Eye off，点击收起整个 Nautilus，包括 Desk 卡片和聚焦对话层；收起后只显示 Eye，点击重新展开。Desk 的保存偏好不变，原始计划大纲仍按既有规则隐藏；展开时恢复海螺与此前开启的 Desk。眼睛不是完成项筛选器。
- **Calendar：** 设置中的 Google Calendar 显示“已连接”后，附加按钮可导入当前图表 Daily Note 的定时忙碌事件和有日期的 Google Tasks。Option/Alt + 点击只强制刷新 Google 托管字段。

隐藏完成项功能仍保持移除：图表展开时，完成片、估时轮廓、连线和标题始终显示；Desk 仍只显示未完成任务。
帮助是临时锚定按钮的浮层，不改变 SVG 大小或 Desk 宽度，也不取代图下的 Tips。小高度视口下可滚动帮助卡，保证全文与指南链接可达。
折叠时关闭帮助，沿用只保留展开按钮的紧凑状态；修改设置会关闭旧帮助，再次打开显示新的有效配置。原生图片查看器打开时会收起帮助，即使焦点未移动也优先让图片接收按键。帮助不读取／写入图谱，也不保存开关偏好。

每个有标题的源记录都保留在图表或待办队列中。固定事件、完成记录／估时、真正排入的任务仍有图形和连接标签。
普通图表标题在 SVG 内换行，不因轨道已满而消失；窄栏仍保留两侧标签、主要小时刻度和紧凑中央日期。
有时段的标题始终留在切片同侧，不为填空翻到另一侧。

画框按左右两列实际显示的标题和局部宽度自适应。密集标签紧凑排列，不再为假设的单侧堆叠撑高画框。
仅当前任务／事件保留 Current 副标题行，其他标题下方不留空行；字号、换行规则、真实时间锚点和螺旋的相对几何不变。

左右列占用、可见 Current 行、源文本或队列成员变化时，高度可以随内容调整；列高度预算不变的普通分钟推进、悬停和打开帮助不改变 SVG 大小。
完整任务可能在 END 之前就放不下，不能为了固定画框保留过期切片。展开队列只增加 SVG 下方的页面内容。

螺旋仍是唯一的时间图形。没有完成状态节点、独立上侧连接带或外圈。下方队列只容纳未完成工作，不是完成记录的重复清单，也不使用内部滚轮。

### 过去日期与未排入任务

查看**过去的 Daily Note** 时，不再把 TODO 从 START 重新排成历史时间片，也不把它们计入过去日的活动 Planned 需求或超载。
它们保留在默认折叠的「未完成」区域，显示原标题、估时和原本的本地 UID。折叠箭头用黄色，浅色背景上的标题用可读的深黄色；计数和时长保持灰色，任务正文用蓝色。
不自动搬到今天、不标记完成。完成估时和固定事件仍留在图中。

今天、未来日期和无法识别日期的页面仍沿用原来的排程顺序；放不进完整连续空档的任务进入「未排入」。空队列不显示。
展开后可读完整标题，点击或 Enter 定位原 block，Shift 在侧栏打开。DONE 估时溢出不会混入未完成队列。
跨午夜窗口到逻辑 END 之前仍属于当天的活动计划，不能到零点就提前归入旧日。

CLOCK 和完成戳都不是绘制估时片的必需条件。本地完成标记（如 `d14:30`）存在时用它定位；
没有时仍按上述规则排布估时。单一精确载体（裸引用或原生 embed）或安全的单一载体链可读取最近显式 DONE 所有者可见且有效的 `dHH:MM`，包括载体后的时长元数据。继承来源终点时只允许已识别的时长元数据；本地完成戳、时间范围、正文、代码或额外引用都会使该终点保持未验证。来源存放页面不是完成日期：Tips 显示「引用时间按当前计划解读」，不会根据页面、编辑、创建、拖入或加载时间猜日期。明确的本地 TODO/DONE 自己拥有状态；本地完成戳或本地 CLOCK 优先，失效的本地／来源完成戳及不可读来源不排入时间轴。含正文、多条引用、代码或其他非时长内容的引用（含中间层）不能提供来源终点；这只限制图表落位，不改变原有 TODO/DONE 继承、任务 UID 或计时归属。

例如来源写有 `d23:54`，未写时长时仍保留默认 **15 分钟估时**，不冒充实际耗时。END 为 20:00 时连接结束边界，不再塞进上午空档；展开 Tips 可查看按计划解读的时刻及估算区间 23:39–23:54。本地标记、本地完成戳及本地 CLOCK 优先，CLOCK 归属和统计仍属于本地；显式零估时不会被补成 15 分钟。跨午夜窗口中，`d01:15` 仍是计划时钟的 01:15，不据此猜来源完成日期。

采用来源完成戳前会核对引用正文和本地 CLOCK 覆盖；读回不一致或无法核对时，保留已完成标题，不制造时间片、边界位置或特殊图标。确实没有完成戳且没有本地 CLOCK 时，才沿用只读「估时排布」：按大纲顺序把整个估时放进从 START 起第一个容得下的空档，避开固定事件和已锚定的完成片。Tips 会说明它不是记录的完成时刻，也不会自动写入 `dHH:MM`。来源正文或所属页面变化会立即重新核对，不必等待分钟刷新。这些计算不补写标记或时间戳、不增加 Actual，也不改变待办排程和容量规则。

悬停或键盘聚焦记录、可用空档、过去空白时段时，提示条按内容自然伸展并居中，两侧保留 16px。
所有宽度的默认预览都固定为两排：标题一排，元信息一排。内容变长时先向两侧扩宽，不受统一的 280px 上限限制；达到当前区域两侧 16px 的边界后，用省略号截断，不自动增加第三排。
短内容不铺满整行；文字被截断或有额外信息时，可主动点击「展开」查看全文。

默认预览为 38px 内容、42px 固定槽位，上下各留 2px。极淡边框配 4px 圆角、上下 4px／左右 6px 内边距，标题和元信息统一为 11px 字号、14px 行高。
「展开」文字与第二行元信息对齐，右侧保留独立的 24px 点击高度，不重叠文字，也不会随长标题拉成一根高按钮；使用次级文字色和悬停／聚焦反馈，不拆词。
空闲时隐藏提示内容，但保留同一个小槽位；在任务、空档和空白处之间移动，不再让下方队列或 Desk 上下跳动。
仅主动展开全文时，阅读区才在正常页面流中长高；全文保持固定，不随悬停换项。收起后恢复两排，不改变 SVG 大小、不遮挡 Desk，也不产生内部滚轮。

标题不使用渐变，跟随图中的语义色：任务蓝色、事件黄色、已完成记录灰色。记录过的完成项在首屏摘要直接标出 Actual；估时排布继续明确标为 Estimate，不冒充真实完成时刻。曲面的渐变只是材质，不表示额外时间或进度；日期、时间信息和空白时段说明保持原色，强制颜色和打印模式保持可读。
过去空白时段显示完整未覆盖区间和时长，不代表实际活动、闲置或浪费。点击或 Enter／Space 固定详情，Escape 关闭；区间变化时旧选择失效。
完成记录与估时始终保留原有时间占用。记录的明确展开也可固定阅读，源记录改变或移除后失效。
说明区不跟随指针，不遮住图形。单击或 Enter 激活弹性任务的图形、标签，只定位原 block；Shift 在侧栏打开。
这些操作不会改写任务或时间；目标折叠时使用 Roam 官方 block 导航。

## Desk 任务视图

开启图表工具栏的 **Desk** 滑动开关，在海螺图下方展开卡片区；关闭开关即可收起。
开关反映真实视图状态，重载偏好或控件重新挂载后也会保持同步。总览工具栏不再显示重复的关闭叉号；Search 和右侧 New task／新任务保留，Tab 从搜索、新建直接进入卡片。编辑弹窗的 Close、背景点击和既有 Esc 行为不变。
使用 Roam 原生 `rm-desk-*` 与 Blueprint 样式，不另外设计字体、字号或卡片主题。
卡片区与上方图表保持相同的本地渲染区域宽度；Daily Notes、侧栏和嵌入区域都不越界，不再扩展到文章外框或使用负边距补偿。
使用原生 masonry：4px 网格行配合实测跨行数，下一张卡可以填入较短卡片下方，不必等待等高整行。
卡片尺寸或图片加载变化后重新测量，不改变 DOM 和任务顺序。列数按实际空间自动填充，不固定为两列或限制为三列。
编辑任务或打开新任务草稿时，后台只读卡片继续响应图谱中已生效的折叠、展开、文本和图片变化，并同步更新瀑布流高度，无需退出编辑。刷新期间保留上一份已核实的预览，不先清空卡片；文本按行更新，未改变的可见图片各自复用原元素，避免在弹窗或侧栏输入时反复闪空、缩高和重载图片。第三张之后的隐藏图片、隐藏数量变化和重新排序不会重建仍在显示的图片；只替换一张已显示图片时，只重新加载那一张。单张与多张布局切换时可以重建该图片区域。实际内容、图片地址和折叠状态改变仍会更新，读取失败仍明确提示。加载失败的图片不会因文字、替代文本或隐藏图片变化而重试；新的显示生命周期或明确重新加载预览时可以重试。

编辑器不重建，焦点、选区、滚动位置和未提交的输入法内容保持原样；聚焦编辑层打开时后台仍不可交互，预览更新不新增图谱写入。

- **只显示未完成任务。** 每个直属 Task 一张卡，包括未排入日程的任务；固定事件、DONE 和
  分隔线不作为卡片。沿用隐式任务和引用状态规则。卡片里的已完成子日志仍保留。
- **隐藏重复大纲。** Desk 展开时，只隐藏当前 Nautilus block 下方的原始子块区域，包括事件
  和已完成日志；不删除内容、不修改 Roam 的展开状态，也不隐藏聚焦编辑器或其他计划的子块。
  收起 Desk 或卸载时恢复原区域。
- **拖拽就是移动原 block。** 目标卡片的左／右半区分别表示前／后（RTL 镜像），会真实更新当前 Nautilus 大纲顺序，
  因而也改变任务优先级和排程。卡片底部悬停时显示 **Move to top**；它把同一个 UID 移到
  原大纲的第 0 位，包含隐藏的事件和完成项在内。拖到第一张活动卡片前面也会真正置顶。
  不复制任务，不改变正文或后代，也不移动引用所指向的可复用来源块。旧版“仅调整视图顺序”和重置布局入口已移除。
  拖动时沿用当前原生 Desk 的右上角灰色位置号、蓝色竖向落点线和插入后序号，不再使用页脚编号或自定义拖影。
  灰色位置号按完整的未完成任务集合编号；搜索不会重编号。Alt 蓝色提示仍按当前可见卡片的前九项编号。
  背景落点表示完整集合末尾，不会因搜索筛选改变真正的插入位置。
- **Remove from Desk** 位于 Move to top 旁边。已核实为当前计划直属子块、没有本地子块且正文精确匹配
  `{{embed-path: ((uid)) closed}}` 的外壳会被删除；既有纯 `((uid))` 引用包装块（前面可有一个 `{{TODO}}` 或 `{{[[TODO]]}}` 标记）也保持原来的删除行为，来源本身不删除。
  普通任务、有上下文的引用、带装饰的 embed 或有本地子块的包装块，都保留同一个 UID 和完整子树，移动到计划所属 Daily Note 页根的末尾。
  历史或未来日期都按真实归属处理，不猜今天或当前路由，不自动建页；无法核实就不操作。
  编辑、输入法组合或其他冲突操作未结束时会拒绝移除；不新增删除快捷键或聚焦菜单写操作。
- **加号新增任务。** 总览的 **New task／新任务** 和聚焦窗口上方的 **＋** 打开原生风格输入区。
  开始输入已提交的非空文本后，在当前 Nautilus block 下创建一个新的直属子块，放在最前面；
  随后交给原生块编辑器继续编辑。打开后直接关闭不会创建空白垃圾块；输入法组合期间不抢先写入。
  不强制添加 TODO 标记；普通文字就是隐式预算任务，没有时长时用默认估时，子级笔记和日志不独立增加需求。
  如果内容被识别为事件或 DONE，它仍会保存，但不显示为活动卡片。
- **原生聚焦编辑。** 点击卡片使用 `renderBlock` 编辑原 UID、路径和子块；Shift + 单击可在侧栏打开。
  聚焦窗按视口居中，最大宽度 880 CSS px，小窗口两侧保留 16px；正文同步利用新增空间。背景侧栏不自动关闭，也不会把聚焦窗挤回窄列；原生高度、字体和字号不变。
  顶栏序号显示当前任务／总数，例如 **1 / 4**，草稿仍显示 **new**。窗口调整只改变排版，不重建编辑器或创建新任务；海螺和卡片总览的宽度保持原样。
  **Option/Alt + 逗号**为 Next，**Option/Alt + 句号**为 Previous。到最后一项不再循环；第一项的
  Previous 进入新任务输入位，与原生 Desk 一致。焦点在已挂载原生编辑器内时，Esc 交给 Roam，
  页脚显示 **esc Roam editor**；焦点移到 Desk 外框后改为 **esc Close**。关闭按钮、背景点击或
  Desk 外框的 Esc 返回卡片区；草稿仍保留自身的 Esc 行为。卡片区还支持按住 Alt 显示序号、**Alt + 1–9** 打开对应卡片。
  从编辑器打开的图片查看器位于聚焦窗上方，点击、滚轮和键盘交给 Roam 原生查看器；Esc 先关闭图片，
  底下的编辑器、选区和滚动位置保持不变。图片关闭后恢复原有 Desk 快捷键行为。
  **键盘快捷键不变。** 横向触控板及 **Shift＋滚轮**按原有方向切卡；小幅手势有跟手反馈和回弹，惯性尾部不会连续跳过多张卡。
  像素、行和页单位会归一化；普通纵向滚动、缩放及内部横向滚动区域仍交给原生处理，输入法和减少动态效果设置受保护。
  始终只挂载当前聚焦的原生编辑器，不通过同时挂载多个可编辑副本换取动画。
- **记住视图模式。** 按图谱和计划 UID 保存 Desk 开关。切页回来、刷新、重载插件，或展开已折叠的图表后都会恢复 Desk，
  不自动打开某张卡片或创建内容。折叠不会改变偏好；显式收起 Desk 才会保存关闭状态。偏好只存在当前浏览器的 localStorage，
  不同步到其他设备，不保存日志正文。手动开启但无法保存偏好时会提示。

### 安全的外部 block 引用

可从同一窗口、同一图谱拖入一个普通原生 Roam block 到卡片或背景。Desk 会保留原 block，
并在当前计划下创建原生 block embed `{{embed-path: ((来源UID)) closed}}`，不自动添加 TODO：普通文本保持普通文本，原有任务复选框不重复。原文、父级及子块均不改动；外壳跟随来源状态，但 CLOCK 和本地计时仍归外壳。既有裸引用和旧引用不会迁移或改写。Desk 仍是未完成项视图；新拖入已完成来源时会明确提示，不擅自重开为 TODO，也不静默创建不可见卡片。
卡片左／右半区分别表示前／后（RTL 镜像），使用相同的原生落点线及插入号；
背景放在完整未完成任务集合的末尾（空计划则第一个）。接受的原生拖入使用复制光标；仅允许 move 或 link 的传输不导入。
文件、页面、query、embed/renderer、事件、跨图谱、多 block 或含糊 payload 会被拒绝。
含修饰键的拖拽则由 Nautilus 忽略，事件完全交给 Roam，不拦截 Roam 自己的修饰键行为。
重复拖放复用同一确定性包装块。旧版生成的 TODO 引用继续作为只读重复项识别，不批量重写或删除已有标记；精确的原生 embed 也只读去重。严格回执读回可识别同一预留 UID 上的裸引用、旧版精确格式或 embed，但新建成功必须匹配本次请求的 embed 正文。
成功添加后，Remove from Desk 只删除无本地子块且正文精确匹配的 embed 外壳；带装饰、本地计时或子块的外壳会原样移到所属 Daily Note，
之后可以再次拖入同一来源，仍使用原来的 UID。被移走的外壳仍占用该 UID，不会新建第二份。
当前视图中结果未确认的请求只做读回验证；后来严格读回同一 UID、正文、父级和无子块的包装块时，解除该请求的占位，
之后确认移除即可重新添加。其他 UID 的引用或直接移入的来源本身不能解除占位。
重载后仍检查同一个预留 UID，不会为相同来源和计划分配第二个 UID。
导入要求公开的 `data.pull`、`data.block.create` API，以及可核对的图谱、类型和用户身份。
进度提示临时使用原有标题区域，不遮挡 Search、New task 或关闭按钮；截断的消息可悬停查看全文，
辅助技术也会收到完整播报。终态提示五秒后清除并恢复标题，不挤动卡片。

导入和 Escape 前置步骤只在合成图谱中验证；Copy 使用内存中的模拟回调。编辑器优先处理 Esc 的修复已实现，
但真实宏流程仍未验证：没有执行物理拖放、真实剪贴板、应用切换、粘贴或发送。

预览采用原生完整 Desk 页规则：根内容加 11 条计数后代行，按大纲顺序显示，最多两层。
前三条纯图片原始行可免计预算；空图片行按层级关系裁剪，图片仍保留并按首次出现顺序去重。
只有明确 `open: false` 才视作折叠；折叠、深度限制和预算截断都会显示 `...`。这是原文投影，不是摘要。
无本地子块的纯引用可展示来源 block／page 的内容和子块；本地子块优先，有上下文的引用不借用另一棵子树。原生 embed 会先展示来源树，再展示本地子块，避免本地 CLOCK／LOGBOOK 把来源内容隐藏。
外部根来源缺失时显示 `(missing)`；代码保持字面内容，不执行不支持的富文本形式，也不冒充完整原生渲染器。
点开卡片仍可编辑完整原文，不修改源 Block 的内容或展开／折叠状态。Search、New task 和关闭 X 使用同一工具组，
宽屏和窄栏都将 X 与＋居中对齐，并保持原来的键盘顺序。卡片根、预览子树和已解析引用中不在
行内／围栏代码中的 Markdown 图片使用 Roam 原生 `rm-desk-tile__image`／`__images` 布局（单张有边界图片，或最多三格）。
只会创建 `http`、`https`、同源 `blob` 和 base64 栅格图片 URL；不会渲染任意图谱 HTML 或不安全 scheme。
除宿主 `<img>` 可解析的 URL 外，未专门适配加密或专有附件的渲染。任务列表共享现有 Plan Pull Watch，
不挂载多个完整编辑器。Search Desk 可搜索标题和预算以外的直属日志内容，不建立递归全文索引。
公开 pull 分阶段读取，引用深度、展开次数、正文、图片、监听和保留模型均有限额。读取或监听失败会明确显示可重试状态；
搜索不完整时保留该卡片，不把未读内容当作不匹配。读取—注册监听—重读会处理注册期间的变化，以及旧监听尚未完成时折叠重开。
任务文字更新不会重建当前编辑器；完成或移出计划后，聚焦转到仍存在的任务。
浏览和切卡不启动 CLOCK，也不修改 Roam 自带的收藏／Desk 卡片集合。

Desk 的移除、移动和新增共用图谱级 `outline` Web Lock。移除还要求公开 `data.pull`、对应的 `data.block.delete`／`move`、
可核对的 Daily Note 日期工具，以及稳定的 provider、图谱、类型和用户身份。操作前检查相关视图、编辑与输入法状态，
重新对比结构和来源快照；只发起一次宿主写操作，再核对 UID、兄弟顺序、来源内容和完整子树。
响应丢失、超时、无变化或无法确认时，本运行期保留只读核验占位，关闭视图不会清除；同计划的其他 Desk 写入也会暂停。
Refresh 只做核验，迟到的操作完成、卡片已消失后也可核验解除占位。不回滚、不盲目重试；占位不是跨插件／浏览器重启的持久事务。
操作前重新核对父级和状态，操作后读回
顺序、UID 和文字；不能确认时明确报错，不把宿主 API 返回成功当成验证成功。无法确认的新建请求
只检查同一个预留 UID，不盲目重复创建。锁不协调其他设备或手动写入者；并发修改会保守地拒绝确认。
读取失败时保留过期卡片并暂停写入；可收起 Desk 检查原始大纲。

### 布局隔离

页面级样式冲突现已复现并修正：旧的嵌入根节点使用 `rm-desk-page`，触发当前宿主修改祖先容器内边距的规则，
在窄栏中造成 12px 横移。现已移除该页面级标记，只在组件内保留原生卡片尺寸，也不再继承整页的 60vh 网格下限。
多种间距和嵌套容器的开关回归保持原有坐标，真正的原生 Desk 页面仍使用自身规则。
仍需在更新后的 Desktop 实例中做一次现场确认；合成测试不代表所有可能的外层留白都已诊断完毕。

`test:desk-polish` 覆盖完整预览、控件对齐、滚轮响应、减少动态效果与清理，可用 `DESK_POLISH_TEST_OUT` 指定目录。
`desk-removal.py` 通过真实页脚控制操作合成图谱（`DESK_REMOVE_TEST_OUT`）；未在正式图谱试删或试移。
`ROAM_NATIVE_CSS`、`ROAM_BLUEPRINT_CSS` 可指向宿主样式快照；`ROAM_ICONS_CSS`、`ROAM_FONT_CSS` 可补充带本地资源路径的
原生图标与字体样式。这些夹具测试不代表已重新验证当前真实 Roam 的 Pull Watch 行为。

2026-10-26 已在真实 Roam 做只读核对：原生 Desk 的 DOM、字体与样式，新视图的五列布局、原生编辑器挂载、
原日志隐藏／恢复、编辑器内子块可见性均已检查；没有试写或重排正式日志。写入行为由隔离夹具验证。
样式与交互依据为 Roam 当前客户端的
[site.css](https://roamresearch.com/assets/css/less-compiled/site.css) 和
[route-app.js](https://roamresearch.com/js/compiled/route-app.js)；不调用其私有压缩函数，也不打包 Roam 客户端源码。

## 渲染器升级

本节的单入口策略替代此前按版本另建源码 UID 的做法。

统一源码入口固定为 `roam-render-Nautilus-Log-r2-cljs`。其中的 `r2` 是保留的历史 UID 字面值，
不表示以后每次源码升级都另建代码块。当前源码版本为 2，使用 `nautilus-log-r2` 命名空间和独立运行桥；
以后源码变化递增源码标记、命名空间及运行桥版本，代码块 UID 保持不变。

统一源码必须是固定代码容器 `roam-render-Nautilus-Log-r2-cljs-header` 的唯一子块；容器名称为 **renderer**。
Roam 会把同父级代码块拼成一个程序，并从其中第一个命名空间选择入口。因此，即使命名空间不同、r2 正文完全正确，
把 v1 与 r2 放在同一容器下，仍可能显示旧版界面。

通用名称 **code** 留给旧版兼容容器：旧安装器在补建源码时会寻找这个名称。已核实、为空或仅有当前源码的旧 `code` 容器，
会原地改名为 `renderer`，保留容器 UID、属性及源码正文。容器保护先于源码／模板准入，
即使源码是自定义、更新版本或有未决回执，也不会跳过这项独立的元数据保护；源码正文和回执保持原样，
不能因此创建或升级源码。活动编辑器或未提交标题不会被覆盖。
混合代码组会在声明就绪或继续安装写入前被阻止，不自动移动、删除或接管其他代码。

已有混组只在用户授权后处理。仍有真实引用的旧源码应独立保留；已更新所有客户端、且引用索引与正文扫描
都确认无用后，应清理旧副本，不要为了存放无用代码再长期增加一个旧容器。
还要检查空的旧版模板入口：正文中的渲染引用可能尚未进入引用索引。保留需要使用的当前模板根及完整子树。

源码缺失时只创建一份，字节相同时直接复用。原地向前升级必须先确认旧正文的 SHA-256 与随包登记的已发布版本一致，
且标题／代码头／源码块仍属于 `roam/render` 下约定的位置。自定义内容、同版本正文差异、未知来源或更新版本均保留并提示。
异步操作后重新核验正文、父级归属、编辑状态以及图谱／用户范围。Git 哈希不用于版本排序；
源码历史保留在 Git，正常更新不在图谱中增加归档副本。

自动迁移只针对一份明确的受管理模板引用，以及活动 Primary Plan 引用；跨夜活动计划可以属于前一日期。
只替换 renderer UID，保留原始前缀、参数文字、属性、子级和顺序。不会覆盖活动编辑器。
多份或结构不支持的模板，以及更新版本根，不会被猜测、改名或向后迁移；更新的 renderer 家族仍被识别为已有计划，避免重复创建。

`roam/render` → `Nautilus Log` 区域保留一份受管理模板。保留 `[[roam/templates]]` 标记时，可以修改模板名称；
插件通过已核实的所属区域和单一渲染根识别它，加载、设置更新和新建计划均复用原 UID 与完整子树。
该区域内的空白、不完整或冲突标记块会被判为不支持，不会被当作“模板不存在”而另建默认模板或退回空计划。
`roam/render` 上既有旧名称模板仍参加同一项歧义检查；其他归属下的无关模板不会被接管。
请把受管理模板留在这一管理区；插件没有跟踪任意跨区域移动的注册表。

有一个渲染根、但没有任务或事件子块的模板，是有效的空模板。重载会保留空树，新建计划只复制这个根，
不会从其他普通笔记中拉回内容或自动补入日程。这不代表可以为了修改外观而清空已有内容的模板。

受管理模板与普通非日期计划使用相同的显示方式，正常呈现容量统计和图表，不再添加专属模板标题。
固定日程、引用任务、预计时长和原生子层级均保留。模板按完整配置时段预览，不随当前时间推进；
实际日期页继续使用各自的时间状态。主窗口、侧栏和嵌入均使用正常布局。

默认模板、渲染引用、代码容器及统一源码入口的 UID 均保持稳定。已有多份旧代码时，可以在明确授权后统一引用：
逐个核验入链，只替换受支持 Render 的源码 UID，确认周围文字与子树未变；只有入链归零且所有客户端均已更新后，才可删除旧源码。
否则旧客户端可能再次补建它。保留的旧源码不得与统一入口共用一个代码容器。
不能仅因某个模板有内容或用了较新 UID，就替用户选它；空模板也可能是有意保留的，选择必须以用户意图为准。

如果提示模板包含多个渲染块，先核对容器，保留需要使用的渲染根及完整子树。
确实废弃的空引用或空管理外壳，在核实没有入链后可以删除；仍被引用的源码和有实际内容的块需要单独处理，不自动清理。
结构修正后重新加载插件，可清除启动时保留的旧提示。插件不会自动选择或删除有歧义的根。
提示跟随整个组件一起折叠，展开后仍可查看，不会覆盖侧栏后面的块。

引用写入前先保存并回读 `renderer-migration-pending`。记录只含图谱／用户标识、UID 和 SHA-256 哈希，
最多 64 条、32 KiB，不保存 block 正文。未确认结果在重载后仍只能核验，不能自动重试或另建计划。
只有内容与记录的 after-hash 完全相同，才撤销该保留记录；另一个有效但不同的 r2 引用不能算作确认。
请检查目标块和原请求，不要通过删除、重建计划绕过未确认状态。

源码升级另用有界的 `renderer-source-upgrade-pending`，同样只凭精确 after-hash 确认，不在设置中保存源码正文。
未确认的源码更新不能重试，也不能通过另建代码块绕过；有未决更新时，缺失的统一源码块不会被重新创建。
源码就绪和新建计划会等待这条记录得到确认。

启动不会扫描或重写历史页面。明确授权的引用统一是单独操作；完成后，历史页面也使用同一个最新代码入口，
日记内容保持原样。未统一旧引用的图谱仍可使用兼容读取器。当前图表、Desk 和帮助继续按自己的运行桥归属清理。
所有客户端都应更新：旧包无法被反向约束，可能重新创建旧结构或继续使用已加载的旧代码。
源码升级后重载已更新的客户端；当前渲染器不依赖可被覆盖的旧全局接口。

## 执行层

可选的执行层默认**关闭**。启用前会隐藏进阶执行设置。关闭时仍有 30px 创建／打开入口和一条
日历当天命令，不启动执行面板、1 秒计时器或 CLOCK 写入者；图表仍可读取既有 LOGBOOK/CLOCK 历史。

没有活动计划时，**＋ 创建今日计划**把模板复制到日历当天。
**Nautilus Log: Create or open today’s Daily Note plan** 始终明确以日历当天为目标，与当前浏览页面无关。
操作冻结单一受管理 renderer 根及完整普通子树，再把副本追加到该 Daily Note。每个新块
都有新 UID；树内引用会重映射，树外引用不变。该页若已有可识别的 Nautilus 组件，包括空
计划或全部完成的计划，则只定位树序 Primary。多个根、模板顶层兄弟、动态/无法读取内容或
缺少所需字段会安全失败，显示具体原因和“查看模板”。LOGBOOK/CLOCK 历史不会复制。
根文本不会从设置重新生成；展开状态、标题、对齐和子项视图类型也会保留。普通创建点击
不经过面板、确认或手动 `;;`。加载或午夜都不会自动创建。

加载中、确认缺失、模板不支持、部分写入和失败分别显示。“重新检查”只重新读取，导航失败
则只重试打开。创建需要确认当前图谱、获得 Web Locks，并保存、读回不含模板正文的记录：
目标 UID、父级、顺序与 SHA-256 哈希。设置不是全局锁；Web Locks 不协调其他设备或手动写入者。

“创建未完成”会显示诊断与已验证块计数。“检查已创建内容”只读且不会清除未完成状态。
只有原内存操作重新验证已写块的文字、属性、父级与顺序后，才能“继续创建”缺失部分。
重载后不能从新模板继续；损坏记录会安全阻止写入。请保留已创建内容检查，不要删除后
反复插入第二份。已占用 UID 不会被覆盖；包括根所属 Daily Note 在内的完整树读回一致
才算成功。

首次模板请求前跨午夜会停止；写入开始后会完成冻结的原日期并提示跨日，不会把昨天标为
今天已就绪。图谱变化或卸载会停止后续工作，但不能回滚已经发出的宿主请求。创建页面后
若模板写入前失败，可能留下空页；尚未发出模板请求的失败可重试。

不会新增逐秒图谱查询。普通检查可复用运行数据；跨夜选择只读取相关的当天、前一天候选，
全局时段缺省时按支持的计划参数判断。检查发生在初始化、返回前台、午夜／END、相关归属变化和明确操作时；
不变的计时 tick 不会反复发现日期或回读模板记录。手动插入的计划在下次检查时发现，不逐键扫描。

开启执行层后，活动工作日 Daily Note 中的第一个 Nautilus Log 会成为顶栏面板使用的
**Primary Plan**。创建成功并读回后，会恢复原有容量文本或 136×4 精力槽，并在主窗口
打开计划。无计划但 CLOCK/POMO 正在运行时，计时和适用的停止控件保持可见；可在面板的
**Plan** 空状态中创建计划。

计划已存在时，单击 Nautilus 顶栏按钮会打开面板；Option/Alt + 单击会在主界面定位 Primary Plan；
Shift + 单击则会在 Roam 右侧边栏打开同一个 block，已存在时只将其移到顶部并展开。

| 视图 | 用途 |
| --- | --- |
| Timing | 当前 Timing Line 与最近结束的任务 |
| Plan | Primary Plan 中尚未完成的直接子级任务 |
| Review | 活动工作日的 Planned、Actual 和有效偏差状态 |

切换任务时，会在同一时刻关闭旧 CLOCK 并打开新 CLOCK。开始前会重新核验正在运行的
CLOCK，不再仅依赖当前标签页的缓存。同一浏览器存储分区内，按图谱使用 Web Locks
串行执行 CLOCK 写入，并通知其他标签页重新读取图谱。无法确认图谱或缺少 Web Locks 时，
会拒绝 CLOCK 写入。此锁不协调其他浏览器配置或设备，也不能保证 Roam 已完成数据同步；
请避免在这些环境同时控制计时。
开启 **Keep Timing Line first in right sidebar** 后，Clock In 还会把当前任务打开或移动
到 Roam 右侧边栏顶部。

面板内可用左右方向键和 Home/End 切换视图。重绘会保留键盘焦点和列表滚动位置；完成任务后，
焦点移到仍存在的任务或当前视图标签。Escape 关闭面板并返回顶栏入口。跨午夜的排程时间
会明确标注“次日”，不再将次日时间截成 `24:00`。

### 活动跨夜工作日

11 月 1 日的 21:00–02:00 计划，在 11 月 2 日 00:30 仍归属 11 月 1 日：逻辑分钟为 1470，剩余 90 分钟。
Plan、容量、任务操作和 Review 共用这个日期。存在全局时段设置时优先采用；缺省时按支持的 renderer 参数判断。
前一天候选无法读取时显示错误，不把它当作不存在。

轻量顶栏入口会打开活动计划，并显示归属日期。执行面板显示工作日日期和 END，另有明确日期的按钮用于
打开／创建日历当天计划；日历当天命令也保持这个明确目标。新建沿用冻结日期、模板、恢复记录和防重复检查，
不会自动重建昨天，也不会在旧“打开”目标消失后悄悄创建第二份计划。

到 END 后切回日历当天；边界不会自动停止 CLOCK 或完成任务。上一工作日的计时仍显示日期并保留 Stop，
不会把旧任务当作新计划内可写的任务。排队操作在获得锁后重新核验归属；已经接受的操作则保留原归属与时刻，
后续 CLOCK／完成写入不会因跨日而改写另一份计划。

### 可选容量精力槽

开启 **用精力槽显示剩余容量** 后，普通单行顶栏标记会变成无金属描边的双层“潜航仪表”。
固定的 136×4px 槽体采用接近 OpenUsage 的纤细比例，两端保持完整圆润，不带描边、阴影
或额外端部装饰。槽体
位于顶栏中心线上方；下层合并成左对齐的
`未分配比例 · 未完成计划总时长`（英文如 `42% free · 3h20m planned`），两行围绕中心线严格上下对折。CLOCK 或 POMO 运行时，
计时与停止按钮直接居中在这条顶栏中心线上，而不是与上方槽体对齐：

- 与 Roam 顶栏右侧图标相同的灰蓝色是扣除全部未完成需求后的弹性余量；
- 较浅的海绿色是今天已被未完成计划预占的容量；
- 更弱的冷灰色空槽是已经流逝的弹性容量；
- `超载 +Xm` 或 `无空档 Xm` 只在下层摘要中以现有警示色出现，不在槽体上重复显示。

所有宽度都以全天弹性容量为同一个分母。固定事件仍从容量中扣除；没有时长的任务仍使用
默认 Todo 时长；顶栏复用现有秒级状态，每分钟重新投影一次，不新增 Roam 读取或计时器。
文本模式与精力槽模式共用当前投影；时间变化只更新读数与排程时间，不替换任务操作按钮。
从面板确认完成任务后，下层精确计划读数保持可见，并在原位做一次短促确认；两条槽层共用
同一次短宽度过渡。写入失败时槽体不变；外部 TODO/DONE 或时长变更会静默重绘，不出现完成
确认。这表示时间容量，不代表身体或心理健康。
完整密度下由双层仪表本身充当点击入口，不再显示最前面的 Nautilus 图标和分隔点；容量
数据不可用或空间不足时才恢复为单独图标，不会在 Roam 搜索框旁留下残缺状态。

### 引用任务的状态所有权

- 裸 `((来源 TODO))` 的 TODO/DONE 状态由真实来源块拥有。从 Nautilus Log 完成任务时，
  插件会把来源 TODO 改为 DONE；CLOCK 仍写在活动工作日的直接外壳下，Actual 归属该工作日。
- 显式外层 `TODO ((来源))` 由今天的外层状态负责。完成时只修改外层标记，不改可复用来源。
- 如果裸引用进入今天之前来源就已经 DONE，它不会进入 Plan 或 Review；如果来源是在今天
  外壳已经产生 Actual 之后变为 DONE，Review 会保留这条今天真实做过的记录。
- 多层引用沿引用链寻找最近的显式 TODO/DONE 所有者。插件只监听 Primary Plan 实际使用的
  精确来源块，不增加全图状态扫描。

Recent 默认保留 45 分钟。独立 POMO 仍在**执行层 · 进阶**内，并共用启动检查：即使只想用 POMO，
也要先关闭单独的 Roam Logbook 扩展。没有新增独立入口或第二套计时运行器。
Pomodoro 阈值默认 45 分钟，只改变实时提示，不会停止工作。
没有任务 CLOCK 时，面板标题栏中的秒表可以启动独立正计时 POMO；运行后同一位置会变成
**停止 POMO**，因此顶栏压缩成单独 Nautilus 图标时仍可结束计时。完成另一项非聚焦任务
不会停止当前 CLOCK，也不会重置其 Pomodoro 周期。遗忘计时提醒默认 120 分钟，同样不会
自动停止或删除 CLOCK。填写 `0` 可以关闭 Recent 或遗忘计时提醒。

## Planned 与 Actual 历史

- 未完成任务使用 Planned 预计时长排程。
- 已完成弹性任务优先使用所属工作日证据范围内的有效 Actual 总时长。
- 多段 CLOCK 仍分别保留在 `LOGBOOK::` 中，海螺图只把总时长合成一个历史切片。
- Actual 即使超过 Planned 也不会被截断。
- 没有 Actual 时，完成项使用明确估时或默认任务时长（默认 15 分钟）。有 `d18:21` 这类本地完成戳时，用它定位。
- 没有这两种本地锚点时，从 START 按大纲顺序排入估时，避开固定事件和已有锚点的历史片。
  虚线轮廓与提示区分估时位置和记录过的完成时刻。真正超出窗口容量时保留标题和估时；缺少 CLOCK 或完成戳不会丢掉时长。
- CLOCK 证据从归属日期的本地午夜开始，至少覆盖到下一日历午夜；跨夜 END 更晚时才继续延伸。
  普通 06:00–20:00 预算仍计入 22:00 的 CLOCK。本地日历边界兼容夏令时变化：时长按实际经过时间计算，显示终点仍是本地钟表时刻。
- 在 21:00–02:00 窗口内，本地 `d00:15` 按次日 00:15 解读；23:30–00:15 的本地 CLOCK 在图表和 Review 中都计为 45 分钟。
  精确 24:00 终点可使用匹配的本地 CLOCK 证据。无日期的引用完成戳仍沿用单独规则，不凭空获得来源完成日期。

Todo Trigger 是可选工具。它追加的完成时间可以提供 `dHH:MM` 锚点，但普通规划与完成
不依赖 Todo Trigger。

Component Prefix 只是新插入组件前的展示文本，可以修改或留空。Primary Plan 根据
Nautilus Log 稳定的 renderer 身份识别组件，不依赖这个标签。

开始时间可选择 00:00–23:00 的任意整点；结束时间可选择 01:00–24:00。结束时间早于
或等于开始时间时，设置中会明确标为 **次日**。例如 21:00–02:00 会成为一个连续的
300 分钟窗口，并始终归属于放置该组件的 Daily Note。旧模板继续兼容，默认值仍为
05:00–21:00。

只有开启 **执行层 · 进阶** 后，设置面板才会展开执行层的其他选项。

Google Calendar 通过一个明确的连接状态行配置：点击 **连接**，选择自己的 Google
账号并批准 Calendar 与 Tasks 的只读权限。设置中会持续显示“已连接”和“断开连接”；
用户不需要填写任何开发者凭据或 Calendar ID。每次图表点击只读取当前日期，不设定时器、
不后台轮询，也不预取未来 7 天。定时 Calendar 事件保持为固定事件；有日期的 Tasks 会
按“默认 Todo 时长”导入为弹性 TODO/DONE。详见
[Google Calendar 同步说明](./google-calendar-sync.md)。

## 本地验收与 API 边界

`npm test` 使用底层假图谱验证实际源查询、冻结、会话与写入适配器；
`PYTHONDONTWRITEBYTECODE=1 npm run test:ui` 包括两个入口的真实会话点击，不以伪造的
成功状态作为创建证据。截图和结果在 `/tmp/nautilus-real-today-plan`。官方 schema/类型
证据及完整边界见[完整模板设计](./plans/2026-09-10-full-template-creation-design.md)。
没有使用真实 Roam Desktop 图谱；原生写入、Pull 和设置持久化仍需现场验证。
`test:renderer-versions` 用完整冻结 v1 和当前 CLJS 测试两种加载顺序，运行真实 bridge/session/watch/Desk 与旧脚手架写入；
`test:overnight-ui` 检查两个入口、明确日期的新建、归属标签、45 分钟 Review、全局时段缺省和 CLOCK 跨 END。
可用 `NAUTILUS_VERSION_OUT`、`NAUTILUS_OVERNIGHT_OUT` 设置独立目录。跳过项不算通过；这些夹具不证明
操作系统输入法、原生原子 Undo、Calendar 授权或跨设备同步。

## 数据与安全

Actual 时间保存为兼容的 Org 风格图谱数据：

```text
{{[[TODO]]}} Task 30m
  - LOGBOOK::
    - CLOCK: [2026-08-22 Sat 10:00]--[2026-08-22 Sat 10:18] => 0:18
```

开启 Actual 前请关闭独立的 Roam Logbook；Nautilus Log 检测到第二个 CLOCK 写入者时会
拒绝启动。一个页面可以有多个图表，但只有活动工作日 Daily Note 中的第一个会成为执行面板的
Primary Plan。面包屑和折叠路径副本会跳过昂贵的图表绘制；右侧边栏使用紧凑图表并默认
折叠 Schedule。卸载插件不会重写或删除用户 block。
