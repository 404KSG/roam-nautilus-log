# Nautilus Log 使用指南

[返回 README](../README.zh-CN.md) · [English](./guide.md)

## 计划格式

把固定事件与弹性任务写成 Nautilus Log 组件的直接子级。Roam block 顺序就是任务优先级。

```text
05:00-06:00 Morning routine
{{[[TODO]]}} 撰写项目简报 45m
{{[[TODO]]}} 复习笔记 30m
11:45-12:30 Lunch
```

- 时间范围会被识别为固定事件。
- 没有时间范围的直接子级会被识别为弹性任务；TODO 可省略，DONE 则不进入今天的执行。
- 预计时长支持 `30m`、`30min`、`1h` 和 `1h30m`。
- 没有时长的任务使用 **Default Todo Duration**。
- **Urgent Trigger Word** 只改变任务颜色，不改变排程顺序。
- 裸 block 引用继承来源的 TODO/DONE；若要在今天重做已完成的来源内容，请在引用外层加 TODO。
- 引用后写入的时长覆盖来源时长；来源的完成时间和 CLOCK 历史不会被今天继承。
- 旧的 `dNN%` 文本不再具有排程含义。Nautilus Log 会把它保留为普通 block 文字，并始终按
  完整预计时长排程。

## 排程规则

1. 固定事件先占用自己声明的时间范围。
2. 按照 Roam block 顺序读取尚未完成的直接子级任务。
3. 从当前时刻开始，把完整任务放进下一个足够大的连续空档。
4. 时间经过后，未完成任务向前推进，但不改变优先顺序。
5. 到设定结束时间仍放不下的任务进入 **今日放不下**。

排程规则完全确定，不会自动生成时长。每项任务保持完整：当前空档放不下时，任务会跳到
下一个合适空档，而不是被任意切开。当前时间仍在固定事件内时，后续待办可以一直保持在该事件结束后开始，
不是卡住了；到 END 放不下的任务则明确标为未排入。分钟计时器与页面恢复可见、聚焦、返回时的校准共用
墙钟快照，同时记录日期，避免隔日同一分钟恢复时沿用旧状态。

## 顶部指标

| 指标 | 含义 |
| --- | --- |
| Planned | 剩余弹性任务需求；`left` 百分比 = `当前剩余灵活时间 ÷ 全天 Available 总量` |
| Remaining | 安排完 Planned 后的余量 |
| Overload | 超出当前可用时间的需求 |
| 空档不足 | 总时间存在，但没有连续空档能容纳某项完整任务 |
| Available | 当前剩余弹性时间 / 完整时段弹性时间总量 |
| Events | 当前剩余事件时间 / 完整时段事件时间总量 |

重叠事件按时间并集计算，同一分钟不会重复统计。小火焰表示当前正在消耗 Available
还是 Event 时间。

## 视觉语言

- 紫色：弹性任务；当前任务使用更强填充和描边
- 普通暖橙：固定事件，不再使用此前偏红、高饱和的鲜橙
- 实心灰色：有本地时间锚点的完成记录
- 灰色加虚线轮廓：按估时排布的完成项，不代表记录过完成时刻
- 淡斜线：已经过去、未被任务或事件区间覆盖的空档，不是未来余量
- 红色指针：现在，也是待办开始排入未来空档的边界
- 红色任务：显式紧急标记覆盖普通色彩

未实际计时的完成任务，按写明的估时绘制；没写则用默认任务时长，默认是 **15 分钟**。
它们直接获得海螺切片和连接标签，不以 CLOCK 或完成戳为门槛。没有本地时间锚点时，
从 START 开始，按大纲顺序将完整估时排入固定事件和已有锚点完成片之间的空档。
提示明确写「估时排布」，不冒充记录过的完成时刻。

估时位置不随红针移动，也不改变待办排程。估时可能排到现在之后，与待办预测重叠；
灰色虚线轮廓区分估时，待办仍保留紫色填充。整个配置窗口确实放不下时，保留任务标题和时长，
用容量溢出端点表示；不拆任务、不让后面的短任务越过它，也不延长 END。
未排入的待办进入图下默认折叠的「未排入」队列，不放在海螺里没有时间含义的位置；显示时段外的已知区间保留方形。

悬停或聚焦标题，会强化当前标题—连线—切片的整条关系。
完成标题保持中性灰蓝，不再画删除线；其他正文仍可读。点击任务仍只定位原 block，不是在图上勾选完成。

过去空档描述的是图上的时间分配，不证明那段时间闲置或“被浪费”。

## 图表控制

- **Desk 滑动开关：** 显示／隐藏图下的未完成任务卡片。平时只显示滑块，悬停或键盘聚焦才显示 Desk 提示；开启时滑块右移、轨道变蓝。支持点击、Space 和 Enter。关闭面板、折叠恢复或读取已保存偏好时，状态同步更新。
- **眼睛：** 默认显示海螺中的已完成事项，可同时切换完成片、估时轮廓、连线和标题。
  只影响海螺图，不隐藏未完成／未排入队列，也不影响 Desk；Desk 仍只显示未完成任务。
- **Calendar：** 设置中的 Google Calendar 显示“已连接”后，导入当前图表 Daily Note
  日期中的定时忙碌事件和有日期的 Google Tasks。Option/Alt + 点击只会强制刷新
  Google 托管字段。
- **整理：** 将已完成任务和已过去固定事件稳定移动到列表最前面，同时保持活动任务的
  相对优先级完全不变。整理只按 UID 移动直属外壳，不修改文本、时间、引用或后代 block；
  若整理后没有继续编辑计划，可撤销一次。
- **折叠：** 会折叠整个已渲染的 Nautilus UI，包括 Desk 卡片、工具栏和聚焦对话层。
  紧凑状态只保留原有的展开按钮；只要 Desk 仍处于开启状态，原始计划大纲就继续隐藏，保存的 Desk 偏好也不会改变。
  展开会恢复海螺图；若此前已选择 Desk，也会恢复其卡片。

每个有标题的源记录都保留在图表或待办队列中。固定事件、完成记录／估时、真正排入的任务仍有图形和连接标签。
普通图表标题在 SVG 内换行，不因轨道已满而消失；窄栏仍保留两侧标签、主要小时刻度和紧凑中央日期。
有时段的标题始终留在切片同侧，不为填空翻到另一侧。

画框按当前图表成员的源标题、状态／区间和局部宽度计算。同一批成员的普通分钟推进、悬停和眼睛切换不改变图框；
任务进入／离开队列、日期关系变化或显式源数据修改，可以重新布局。完整任务可能在 END 之前就放不下，不能为了固定画框保留过期切片。
展开队列只增加下方页面内容，不改变 SVG 几何。

螺旋仍是唯一的时间图形。没有完成状态节点、独立上侧连接带或外圈。下方队列只容纳未完成工作，不是完成记录的重复清单，也不使用内部滚轮。

### 过去日期与未排入任务

查看**过去的 Daily Note** 时，不再把 TODO 从 START 重新排成历史时间片，也不把它们计入过去日的活动 Planned 需求或超载。
它们保留在默认折叠的「未完成」区域，显示原标题、估时和原本的本地 UID。标题与折叠箭头用橙色提示，计数、时长与任务正文保持各自颜色。
不自动搬到今天、不标记完成。完成估时和固定事件仍留在图中。

今天、未来日期和无法识别日期的页面仍沿用原来的排程顺序；放不进完整连续空档的任务进入「未排入」。空队列不显示。
展开后可读完整标题，点击或 Enter 定位原 block，Shift 在侧栏打开。DONE 估时溢出不会混入未完成队列。
跨午夜窗口到逻辑 END 之前仍属于当天的活动计划，不能到零点就提前归入旧日。

CLOCK 和完成戳都不是绘制估时片的必需条件。本地完成标记（如 `d14:30`）存在时用它定位；
没有时仍按上述规则排布估时。引用继承的完成状态会说明来源，不拿来源的旧时间或最后编辑时间
冒充今天的外壳完成时刻。估时排布不写回时间戳、不增加 Actual，也不改变待办排程或容量计算。

悬停或键盘聚焦记录、可用空档、过去空白时段时，提示条按内容自然伸展并居中，两侧保留 16px。
本地宽度大于 360px 时，不恢复 280px 上限：标题和当前元信息完整显示，过长则换行，不用省略号。
短内容不铺满整行；「展开」只补充额外信息，不负责解锁宽视图标题。宽度不超过 360px 时可保留紧凑预览和全文入口。

普通提示为 38px 内容、42px 最小占位，上下各留 2px。极淡边框配 4px 圆角、上下 4px／左右 6px 内边距，标题和元信息统一为 11px 字号、14px 行高。
「展开」文字与第二行元信息对齐，右侧保留独立的 24px 点击高度，不重叠文字，也不会随长标题拉成一根高按钮；使用次级文字色和悬停／聚焦反馈，不拆词。
宽视图换行或明确展开时，只让文字区在正常页面流长高，不改变 SVG 大小，不遮挡 Desk，不产生内部滚轮。
图形底部额外空白保持 2px，中心、时间路径和标签位置不变。

标题取消渐变，跟随图中的语义色：任务紫色、事件暖橙色、已完成记录灰色；日期、时间信息和空白时段说明保持原色，强制颜色和打印模式保持可读。
过去空白时段显示完整未覆盖区间和时长，不代表实际活动、闲置或浪费。点击或 Enter／Space 固定详情，Escape 关闭；区间变化时旧选择失效。
隐藏完成记录不改变其时间占用。记录的明确展开也可固定阅读，源记录改变或移除后失效。
说明区不跟随指针，不遮住图形。单击或 Enter 激活弹性任务的图形、标签，只定位原 block；Shift 在侧栏打开。
这些操作不会改写任务或时间；目标折叠时使用 Roam 官方 block 导航。

## Desk 任务视图

开启图表工具栏的 **Desk** 滑动开关，在海螺图下方展开卡片区；关闭开关即可收起。
开关反映真实视图状态，重载偏好或控件重新挂载后也会保持同步。
使用 Roam 原生 `rm-desk-*` 与 Blueprint 样式，不另外设计字体、字号或卡片主题。
卡片区与上方图表保持相同的本地渲染区域宽度；Daily Notes、侧栏和嵌入区域都不越界，不再扩展到文章外框或使用负边距补偿。
使用原生 masonry：4px 网格行配合实测跨行数，下一张卡可以填入较短卡片下方，不必等待等高整行。
卡片尺寸或图片加载变化后重新测量，不改变 DOM 和任务顺序。列数按实际空间自动填充，不固定为两列或限制为三列。

- **只显示未完成任务。** 每个直属 Task 一张卡，包括未排入日程的任务；固定事件、DONE 和
  分隔线不作为卡片。沿用隐式任务和引用状态规则。卡片里的已完成子日志仍保留。
- **隐藏重复大纲。** Desk 展开时，只隐藏当前 Nautilus block 下方的原始子块区域，包括事件
  和已完成日志；不删除内容、不修改 Roam 的展开状态，也不隐藏聚焦编辑器或其他计划的子块。
  收起 Desk 或卸载时恢复原区域。
- **拖拽就是移动原 block。** 目标卡片的左／右半区分别表示前／后（RTL 镜像），会真实更新当前 Nautilus 大纲顺序，
  因而也改变任务优先级和排程。卡片底部悬停时显示 **Move to top**；它把同一个 UID 移到
  原大纲的第 0 位，包含隐藏的事件和完成项在内。拖到第一张活动卡片前面也会真正置顶。
  不复制任务，不改变正文或后代，也不移动引用所指向的可复用来源块。旧版“仅调整视图顺序”和重置布局入口已移除。
  拖动时沿用当前原生 Desk 的右上角灰色位置号、蓝色竖向落点线和插入后序号，不再使用页脚编号或自定义拖影。
  灰色位置号按完整的未完成任务集合编号；搜索不会重编号。Alt 蓝色提示仍按当前可见卡片的前九项编号。
  背景落点表示完整集合末尾，不会因搜索筛选改变真正的插入位置。
- **Remove from Desk** 位于 Move to top 旁边。只有已核实为当前计划直属子块、没有本地子块或额外正文的纯 `((uid))` 引用包装块，
  才会被删除；引用前可以有一个 `{{TODO}}` 或 `{{[[TODO]]}}` 标记，引用来源本身不删除。
  普通任务、有上下文的引用、有本地子块的包装块，都保留同一个 UID 和完整子树，移动到计划所属 Daily Note 页根的末尾。
  历史或未来日期都按真实归属处理，不猜今天或当前路由，不自动建页；无法核实就不操作。
  编辑、输入法组合或其他冲突操作未结束时会拒绝移除；不新增删除快捷键或聚焦菜单写操作。
- **加号新增内容。** 总览的 **New note** 和聚焦窗口上方的 **＋** 打开原生风格输入区。
  开始输入已提交的非空文本后，在当前 Nautilus block 下创建一个新的直属子块，放在最前面；
  随后交给原生块编辑器继续编辑。打开后直接关闭不会创建空白垃圾块；输入法组合期间不抢先写入。
  不强制添加 TODO 标记；如果内容被识别为事件或 DONE，它仍会保存，但不显示为活动卡片。
- **原生聚焦编辑。** 点击卡片使用 `renderBlock` 编辑原 UID、路径和子块；Shift + 单击可在侧栏打开。
  **Option/Alt + 逗号**为 Next，**Option/Alt + 句号**为 Previous。到最后一项不再循环；第一项的
  Previous 进入新笔记输入位，与原生 Desk 一致。焦点在已挂载原生编辑器内时，Esc 交给 Roam，
  页脚显示 **esc Roam editor**；焦点移到 Desk 外框后改为 **esc Close**。关闭按钮、背景点击或
  Desk 外框的 Esc 返回卡片区；草稿仍保留自身的 Esc 行为。卡片区还支持按住 Alt 显示序号、**Alt + 1–9** 打开对应卡片。
  **键盘快捷键不变。** 横向触控板及 **Shift＋滚轮**按原有方向切卡；小幅手势有跟手反馈和回弹，惯性尾部不会连续跳过多张卡。
  像素、行和页单位会归一化；普通纵向滚动、缩放及内部横向滚动区域仍交给原生处理，输入法和减少动态效果设置受保护。
  始终只挂载当前聚焦的原生编辑器，不通过同时挂载多个可编辑副本换取动画。
- **记住视图模式。** 按图谱和计划 UID 保存 Desk 开关。切页回来、刷新、重载插件，或展开已折叠的图表后都会恢复 Desk，
  不自动打开某张卡片或创建内容。折叠不会改变偏好；显式收起 Desk 才会保存关闭状态。偏好只存在当前浏览器的 localStorage，
  不同步到其他设备，不保存日志正文。手动开启但无法保存偏好时会提示。

### 安全的外部 block 引用

可从同一窗口、同一图谱拖入一个普通原生 Roam block 到卡片或背景。Desk 会保留原 block，
并在当前计划下创建一个本地 `TODO` 引用包装块。卡片左／右半区分别表示前／后（RTL 镜像），使用相同的原生落点线及插入号；
背景放在完整未完成任务集合的末尾（空计划则第一个）。接受的原生拖入使用复制光标；仅允许 move 或 link 的传输不导入。
文件、页面、query、embed/renderer、事件、跨图谱、多 block 或含糊 payload 会被拒绝。
含修饰键的拖拽则由 Nautilus 忽略，事件完全交给 Roam，不拦截 Roam 自己的修饰键行为。
重复拖放复用同一确定性包装块；当前视图中结果未确认的请求只做读回验证。重载后仍检查同一个预留 UID，
不会为相同来源和计划分配第二个 UID。导入要求公开的 `data.pull`、`data.block.create` API，以及可核对的图谱、类型和用户身份。
进度提示临时使用原有标题区域，不遮挡 Search、New note 或关闭按钮；截断的消息可悬停查看全文，
辅助技术也会收到完整播报。终态提示五秒后清除并恢复标题，不挤动卡片。

导入和 Escape 前置步骤只在合成图谱中验证；Copy 使用内存中的模拟回调。编辑器优先处理 Esc 的修复已实现，
但真实宏流程仍未验证：没有执行物理拖放、真实剪贴板、应用切换、粘贴或发送。

预览采用原生完整 Desk 页规则：根内容加 11 条计数后代行，按大纲顺序显示，最多两层。
前三条纯图片原始行可免计预算；空图片行按层级关系裁剪，图片仍保留并按首次出现顺序去重。
只有明确 `open: false` 才视作折叠；折叠、深度限制和预算截断都会显示 `...`。这是原文投影，不是摘要。
无本地子块的纯引用可展示来源 block／page 的内容和子块；本地子块优先，有上下文的引用不借用另一棵子树。
外部根来源缺失时显示 `(missing)`；代码保持字面内容，不执行不支持的富文本形式，也不冒充完整原生渲染器。
点开卡片仍可编辑完整原文，不修改源 Block 的内容或展开／折叠状态。Search、New note 和关闭 X 使用同一工具组，
宽屏和窄栏都将 X 与＋居中对齐，并保持原来的键盘顺序。卡片根、预览子树和已解析引用中不在
行内／围栏代码中的 Markdown 图片使用 Roam 原生 `rm-desk-tile__image`／`__images` 布局（单张有边界图片，或最多三格）。
只会创建 `http`、`https`、同源 `blob` 和 base64 栅格图片 URL；不会渲染任意图谱 HTML 或不安全 scheme。
除宿主 `<img>` 可解析的 URL 外，未专门适配加密或专有附件的渲染。任务列表共享现有 Plan Pull Watch，
不挂载多个完整编辑器。Search Desk 可搜索标题和预算以外的直属日志内容，不建立递归全文索引。
公开 pull 分阶段读取，引用深度、展开次数、正文、图片、监听和保留模型均有限额。读取或监听失败会明确显示可重试状态；
搜索不完整时保留该卡片，不把未读内容当作不匹配。读取—注册监听—重读会处理注册期间的变化，以及旧监听尚未完成时折叠重开。
任务文字更新不会重建当前编辑器；完成或移出计划后，聚焦转到仍存在的任务。
浏览和切卡不启动 CLOCK，也不修改 Roam 自带的收藏／Desk 卡片集合。

移除、移动和新增使用与 Tidy 共用的图谱 `outline` Web Lock。移除还要求公开 `data.pull`、对应的 `data.block.delete`／`move`、
可核对的 Daily Note 日期工具，以及稳定的 provider、图谱、类型和用户身份。操作前检查相关视图、编辑与输入法状态，
重新对比结构和来源快照；只发起一次宿主写操作，再核对 UID、兄弟顺序、来源内容和完整子树。
响应丢失、超时、无变化或无法确认时，本运行期保留只读核验占位，关闭视图不会清除；同计划的其他 Desk 写入也会暂停。
Refresh 只做核验，迟到的操作完成、卡片已消失后也可核验解除占位。不回滚、不盲目重试；占位不是跨插件／浏览器重启的持久事务。
操作前重新核对父级和状态，操作后读回
顺序、UID 和文字；不能确认时明确报错，不把宿主 API 返回成功当成验证成功。无法确认的新建请求
只检查同一个预留 UID，不盲目重复创建。锁不协调其他设备或手动写入者；并发修改会保守地拒绝确认。
读取失败时保留过期卡片并暂停写入；可收起 Desk 检查原始大纲。

### 临时 Desk 诊断（Draft 预览）

诊断**默认关闭**，重载后也会复位。通过 Roam 命令面板操作：

1. 运行 **Nautilus Log: Start Desk diagnostics (temporary)**，再复现问题。
2. 运行 **Nautilus Log: Show Desk diagnostics** 查看报告。**Capture layout** 补采当前布局；
   **Download report** 导出本地 JSON 文件。
3. 运行 **Nautilus Log: Stop and clear Desk diagnostics**，或点击 **Close diagnostics**，停止观察并清空内存报告。

报告最多保留 40 条事件，只包含布局尺寸、滚动位置及固定的视图切换／弹窗关闭原因。
不记录笔记正文、输入内容、原始按键、URL、图谱／Block 标识或凭据；不使用持久存储、不发送数据、不写图谱。
只有主动点击 Download report 才会导出文件；可用时会附带源码版本。报告面板不会锁定页面滚动或自动抢走编辑焦点。

页面级样式冲突现已复现并修正：旧的嵌入根节点使用 `rm-desk-page`，触发当前宿主修改祖先容器内边距的规则，
在窄栏中造成 12px 横移。现已移除该页面级标记，只在组件内保留原生卡片尺寸，也不再继承整页的 60vh 网格下限。
多种间距和嵌套容器的开关回归保持原有坐标，真正的原生 Desk 页面仍使用自身规则。
仍需在更新后的 Desktop 实例中做一次现场确认；合成测试不代表所有可能的外层留白都已诊断完毕。

## 执行层

可选的执行层默认**关闭**。启用前会隐藏进阶执行设置。关闭时仍会加载 30px 的今日计划
入口和一条创建/打开命令，但不会加载执行面板、1 秒计时器、CLOCK 写入者或 LOGBOOK
读取。

点击 **＋ 创建今日计划**（或命令），会冻结单一受管理 Nautilus renderer 根及其完整
普通子树，并把新副本追加到本地日历“今天”的 Daily Note，和当前浏览页面无关。每个新块
都有新 UID；树内引用会重映射，树外引用不变。该页若已有可识别的 Nautilus 组件，包括空
计划或全部完成的计划，则只定位树序 Primary。多个根、模板顶层兄弟、动态/无法读取内容或
缺少所需字段会安全失败，显示具体原因和“查看模板”。LOGBOOK/CLOCK 历史不会复制。
根文本不会从设置重新生成；展开状态、标题、对齐和子项视图类型也会保留。普通创建点击
不经过面板、确认或手动 `;;`。加载或午夜都不会自动创建。

加载中、确认缺失、模板不支持、部分写入和失败分别显示。“重新检查”只重新读取，导航失败
则只重试打开。创建需要确认当前图谱、获得 Web Locks，并保存、读回不含模板正文的记录：
目标 UID、父级、顺序与 SHA-256 哈希。设置不是全局锁；Web Locks 不协调其他设备或手动写入者。

“创建未完成”会显示诊断与已验证块计数。“检查已创建内容”只读且不会清除未完成状态。
只有原内存操作重新验证已写块的文字、属性、父级与顺序后，才能“继续创建”缺失部分。
重载后不能从新模板继续；损坏记录会安全阻止写入。请保留已创建内容检查，不要删除后
反复插入第二份。已占用 UID 不会被覆盖；包括根所属 Daily Note 在内的完整树读回一致
才算成功。

首次模板请求前跨午夜会停止；写入开始后会完成冻结的原日期并提示跨日，不会把昨天标为
今天已就绪。图谱变化或卸载会停止后续工作，但不能回滚已经发出的宿主请求。创建页面后
若模板写入前失败，可能留下空页；尚未发出模板请求的失败可重试。

不会新增逐秒图谱查询。执行层开启时复用运行数据，关闭时只在初始化、节流后的回到前台、
午夜及明确操作时检查。手动用 `;;` 插入的计划会在下次检查时被发现，不会逐键扫描。

开启执行层后，当天 Daily Note 中的第一个 Nautilus Log 会成为顶栏面板使用的
**Primary Plan**。创建成功并读回后，会恢复原有容量文本或 136×4 精力槽，并在主窗口
打开计划。无计划但 CLOCK/POMO 正在运行时，计时和适用的停止控件保持可见；可在面板的
**Plan** 空状态中创建计划。

计划已存在时，单击 Nautilus 顶栏按钮会打开面板；Option/Alt + 单击会在主界面定位 Primary Plan；
Shift + 单击则会在 Roam 右侧边栏打开同一个 block，已存在时只将其移到顶部并展开。

| 视图 | 用途 |
| --- | --- |
| Timing | 当前 Timing Line 与最近结束的任务 |
| Plan | Primary Plan 中尚未完成的直接子级任务 |
| Review | 当天 Planned、Actual 和有效偏差状态 |

切换任务时，会在同一时刻关闭旧 CLOCK 并打开新 CLOCK。开始前会重新核验正在运行的
CLOCK，不再仅依赖当前标签页的缓存。同一浏览器存储分区内，按图谱使用 Web Locks
串行执行 CLOCK 写入，并通知其他标签页重新读取图谱。无法确认图谱或缺少 Web Locks 时，
会拒绝 CLOCK 写入。此锁不协调其他浏览器配置或设备，也不能保证 Roam 已完成数据同步；
请避免在这些环境同时控制计时。
开启 **Keep Timing Line first in right sidebar** 后，Clock In 还会把当前任务打开或移动
到 Roam 右侧边栏顶部。

面板内可用左右方向键和 Home/End 切换视图。重绘会保留键盘焦点和列表滚动位置；完成任务后，
焦点移到仍存在的任务或当前视图标签。Escape 关闭面板并返回顶栏入口。跨午夜的排程时间
会明确标注“次日”，不再将次日时间截成 `24:00`。

### 可选容量精力槽

开启 **用精力槽显示剩余容量** 后，普通单行顶栏标记会变成无金属描边的双层“潜航仪表”。
固定的 136×4px 槽体采用接近 OpenUsage 的纤细比例，两端保持完整圆润，不带描边、阴影
或额外端部装饰。槽体
位于顶栏中心线上方；下层合并成左对齐的
`百分比 left · 未完成计划总时长`，两行围绕中心线严格上下对折。CLOCK 或 POMO 运行时，
计时与停止按钮直接居中在这条顶栏中心线上，而不是与上方槽体对齐：

- 与 Roam 顶栏右侧图标相同的灰蓝色是扣除全部未完成需求后的弹性余量；
- 较浅的海绿色是今天已被未完成计划预占的容量；
- 更弱的冷灰色空槽是已经流逝的弹性容量；
- `超载 +Xm` 或 `无空档 Xm` 只在下层摘要中以现有警示色出现，不在槽体上重复显示。

所有宽度都以全天弹性容量为同一个分母。固定事件仍从容量中扣除；没有时长的任务仍使用
默认 Todo 时长；顶栏复用现有秒级状态，每分钟重新投影一次，不新增 Roam 读取或计时器。
精力槽模式下，打开的面板共用同一计算结果，时间变化只更新读数和排程时间，不替换任务
操作按钮。关闭精力槽时，仍保留原有文本模式的缓存更新方式。
从面板确认完成任务后，下层精确计划读数保持可见，并在原位做一次短促确认；两条槽层共用
同一次短宽度过渡。写入失败时槽体不变；外部 TODO/DONE 或时长变更会静默重绘，不出现完成
确认。这表示时间容量，不代表身体或心理健康。
完整密度下由双层仪表本身充当点击入口，不再显示最前面的 Nautilus 图标和分隔点；容量
数据不可用或空间不足时才恢复为单独图标，不会在 Roam 搜索框旁留下残缺状态。

### 引用任务的状态所有权

- 裸 `((来源 TODO))` 的 TODO/DONE 状态由真实来源块拥有。从 Nautilus Log 完成任务时，
  插件会把来源 TODO 改为 DONE；CLOCK 仍写在今天的直接外壳下，因此 Actual 仍属于今天。
- 显式外层 `TODO ((来源))` 由今天的外层状态负责。完成时只修改外层标记，不改可复用来源。
- 如果裸引用进入今天之前来源就已经 DONE，它不会进入 Plan 或 Review；如果来源是在今天
  外壳已经产生 Actual 之后变为 DONE，Review 会保留这条今天真实做过的记录。
- 多层引用沿引用链寻找最近的显式 TODO/DONE 所有者。插件只监听 Primary Plan 实际使用的
  精确来源块，不增加全图状态扫描。

Recent 默认保留 45 分钟。Pomodoro 阈值默认 45 分钟，只改变实时提示，不会停止工作。
没有任务 CLOCK 时，面板标题栏中的秒表可以启动独立正计时 POMO；运行后同一位置会变成
**停止 POMO**，因此顶栏压缩成单独 Nautilus 图标时仍可结束计时。完成另一项非聚焦任务
不会停止当前 CLOCK，也不会重置其 Pomodoro 周期。遗忘计时提醒默认 120 分钟，同样不会
自动停止或删除 CLOCK。填写 `0` 可以关闭 Recent 或遗忘计时提醒。

## Planned 与 Actual 历史

- 未完成任务使用 Planned 预计时长排程。
- 已完成弹性任务优先使用当天有效 Actual 总时长。
- 多段 CLOCK 仍分别保留在 `LOGBOOK::` 中，海螺图只把总时长合成一个历史切片。
- Actual 即使超过 Planned 也不会被截断。
- 没有 Actual 时，完成项使用明确估时或默认任务时长（默认 15 分钟）。有 `d18:21` 这类本地完成戳时，用它定位。
- 没有这两种本地锚点时，从 START 按大纲顺序排入估时，避开固定事件和已有锚点的历史片。
  虚线轮廓与提示区分估时位置和记录过的完成时刻。真正超出窗口容量时保留标题和估时；缺少 CLOCK 或完成戳不会丢掉时长。
- 使用跨午夜图表窗口时，次日延续区间内的 CLOCK 仍归属于创建该计划的 Daily Note。

Todo Trigger 是可选工具。它追加的完成时间可以提供 `dHH:MM` 锚点，但普通规划与完成
不依赖 Todo Trigger。

## 数据与安全

Actual 时间保存为兼容的 Org 风格图谱数据：

```text
{{[[TODO]]}} Task 30m
  - LOGBOOK::
    - CLOCK: [2026-08-22 Sat 10:00]--[2026-08-22 Sat 10:18] => 0:18
```

开启 Actual 前请关闭独立的 Roam Logbook；Nautilus Log 检测到第二个 CLOCK 写入者时会
拒绝启动。一个页面可以有多个图表，但只有今天 Daily Note 中的第一个会成为执行面板的
Primary Plan。面包屑和折叠路径副本会跳过昂贵的图表绘制；右侧边栏使用紧凑图表并默认
折叠 Schedule。卸载插件不会重写或删除用户 block。
